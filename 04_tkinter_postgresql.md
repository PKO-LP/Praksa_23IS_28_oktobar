# Занятие 4. Загружаем алканы из PostgreSQL в Tkinter

Продолжение [занятия 3](03_tkinter_vruchnuyu.md). Заменим три ручные строки загрузкой десяти записей по кнопке **«Показать»**. Интерфейс остаётся в одном главном окне. Собственные классы не создаём.

Нужны результаты всех предыдущих занятий: база `organic_chemistry`, таблица `public.alkanes`, установленный Psycopg 3 и работающий `gui_manual.py`.

Связываем Python с **сервером PostgreSQL**. pgAdmin служит для управления и проверки; приложение не подключается к программе pgAdmin.

## Шаг 1. Сохраните ручной вариант

Скопируйте `gui_manual.py` в файл `gui_database.py` в той же папке. Все дальнейшие изменения делайте в копии.

Запустите:

```bash
python gui_database.py
```

**Проверка:** пока видны три ручных алкана, кнопка очистки работает. Закройте окно.

## Шаг 2. Подключите библиотеку

В самом начале файла **под `from tkinter import ttk`** добавьте:

```python
import psycopg
```

Сохраните и запустите файл. Внешний вид не изменится. Если возникает `ModuleNotFoundError`, вернитесь к установке и проверке интерпретатора в [занятии 2](02_zaprosy_i_python.md).

Импорт библиотеки ещё не открывает подключение к серверу.

## Шаг 3. Отключите ручное заполнение

Внизу файла найдите три вызова `таблица.insert(...)`. Поставьте перед каждым `#`:

```python
# таблица.insert("", tk.END, values=("Метан", "CH4", 1))
# таблица.insert("", tk.END, values=("Этан", "C2H6", 2))
# таблица.insert("", tk.END, values=("Пропан", "C3H8", 3))
```

Можно удалить эти строки. Комментирование помогает наглядно сохранить прежний способ. Не комментируйте создание таблицы и `mainloop()`.

**Проверка:** после запуска видны заголовки и нет записей. Это ожидаемый промежуточный результат: старый источник отключён, новый пока не добавлен.

## Шаг 4. Добавьте получение данных в функцию

Найдите функцию `очистить_таблицу()`. **После её тела, перед `окно = tk.Tk()`** определите новую функцию. Строка `def` начинается без отступа:

```python
def показать_алканы():
    with psycopg.connect(
        dbname="organic_chemistry",
        user="postgres",
        password="ВАШ_ПАРОЛЬ",
        host="localhost",
        port=5432,
        connect_timeout=5
    ) as соединение:
        with соединение.cursor() as курсор:
            курсор.execute("""
                SELECT name, formula, carbon_count
                FROM public.alkanes
                ORDER BY carbon_count ASC
            """)
            алканы = курсор.fetchall()

    print(алканы)
```

Вставьте те же рабочие параметры подключения, что в `console_alkanes.py`. Не переносите сюда фильтр `минимум = 7`: сначала нужны все десять строк.

Это уже знакомые подключение, курсор и запрос. Новое: теперь они находятся в функции, поэтому выполняются по вызову, а не сразу при открытии окна.

Последняя печать пока временная: она поможет проверить БД отдельно от вывода в таблицу. Переменная `алканы` локальна функции; использовать её будем в этой же функции.

## Шаг 5. Добавьте кнопку «Показать»

Найдите строку `надпись.pack(pady=10)`. **Сразу после неё, перед существующей кнопкой очистки** добавьте:

```python
кнопка_показать = ttk.Button(
    окно,
    text="Показать",
    command=показать_алканы
)
кнопка_показать.pack(pady=5)
```

Оставьте `command=показать_алканы` без скобок. Функция определена выше, а выполнится только при нажатии, после создания всех виджетов.

**Проверка:** запустите файл из терминала и нажмите «Показать». В терминале появился список десяти кортежей, в таблице пока пусто. Если подключение не работает, сначала исправьте его по подсказкам занятия 2.

Не двигайтесь дальше, пока не увидите правильный список. Так вы понимаете, какой этап цепочки уже работает.

## Шаг 6. Замените временную печать заполнением виджета

В функции `показать_алканы()` найдите строку `print(алканы)`. **Удалите её и вместо неё добавьте следующий блок**:

```python
    очистить_таблицу()

    for алкан in алканы:
        название = алкан[0]
        формула = алкан[1]
        число_атомов = алкан[2]
        таблица.insert("", tk.END, values=(название, формула, число_атомов))
```

Важно расположение: `очистить_таблицу()` и `for` имеют отступ **четыре пробела**, то есть находятся внутри функции, но **после внешнего `with`**. Тело цикла имеет восемь пробелов.

Разберите изменение по смыслу:

1. Запрос получает свежие строки.
2. `fetchall()` сохраняет их в список.
3. После завершения подключения очищаем прежнее содержимое виджета.
4. Из очередного кортежа получаем три значения.
5. Знакомый `insert()` выводит их через переменные.

Раньше было `values=("Метан", "CH4", 1)`. Теперь — `values=(название, формула, число_атомов)`. Порядок значений соответствует порядку `SELECT` и `columns`.

Очищаем **после успешного чтения**, чтобы при ошибке запроса прежнее содержимое не исчезало. В базовом варианте сообщение об ошибке будет в терминале.

## Шаг 7. Проверьте полную цепочку

1. Запустите приложение: таблица пуста.
2. Нажмите **«Показать»**: появились десять строк, от метана до декана.
3. Нажмите **«Показать»** ещё раз: строк по-прежнему десять, дубликатов нет.
4. Нажмите **«Очистить таблицу»**: записи исчезли, заголовки остались.
5. Снова нажмите **«Показать»**: десять строк вернулись.
6. Выполните в pgAdmin `SELECT COUNT(*) FROM public.alkanes;`: результат по-прежнему `10`.

Почему десять строк вернулись? Очистка удаляет элементы интерфейса, а не записи базы. В программе нет SQL-команды `DELETE`.

Это загрузка по нажатию: строки не вписаны вручную и подгружаются программой из БД. Изменения базы сами по себе не вызывают обновление окна — для нового чтения нужна кнопка.

## Шаг 8. Свяжите интерфейс с условиями из занятия 2

Внутри `курсор.execute(...)` **между `FROM` и `ORDER BY`** временно добавьте:

```sql
WHERE carbon_count BETWEEN 3 AND 6
```

Это строка внутри уже существующих тройных кавычек Python, отдельные тройные кавычки не добавляйте. Сохраните, перезапустите программу, нажмите «Показать».

**Проверка:** четыре строки — пропан, бутан, пентан, гексан. Цикл вставки не менялся: он подходит для любого числа полученных записей.

Теперь замените условие на `WHERE carbon_count > 20`. После перезапуска и нажатия таблица должна быть пустой: запрос успешен, но подходящих строк нет.

**Верните запрос без `WHERE`**, чтобы итоговая версия показывала весь каталог. После изменения Python-файла требуется перезапуск приложения: уже открытое окно продолжает выполнять старый код.

## Контрольный итоговый файл

В этом варианте ручные вставки удалены, временная печать убрана, фильтр отключён. Используйте для сверки после самостоятельной сборки.

```python
import tkinter as tk
from tkinter import ttk
import psycopg


def очистить_таблицу():
    for строка in таблица.get_children():
        таблица.delete(строка)


def показать_алканы():
    with psycopg.connect(
        dbname="organic_chemistry",
        user="postgres",
        password="ВАШ_ПАРОЛЬ",
        host="localhost",
        port=5432,
        connect_timeout=5
    ) as соединение:
        with соединение.cursor() as курсор:
            курсор.execute("""
                SELECT name, formula, carbon_count
                FROM public.alkanes
                ORDER BY carbon_count ASC
            """)
            алканы = курсор.fetchall()

    очистить_таблицу()

    for алкан in алканы:
        название = алкан[0]
        формула = алкан[1]
        число_атомов = алкан[2]
        таблица.insert("", tk.END, values=(название, формула, число_атомов))


окно = tk.Tk()
окно.title("Алканы — органическая химия")
окно.geometry("680x420")

надпись = ttk.Label(окно, text="Каталог алканов")
надпись.pack(pady=10)

кнопка_показать = ttk.Button(
    окно,
    text="Показать",
    command=показать_алканы
)
кнопка_показать.pack(pady=5)

кнопка_очистки = ttk.Button(
    окно,
    text="Очистить таблицу",
    command=очистить_таблицу
)
кнопка_очистки.pack(pady=5)

таблица = ttk.Treeview(
    окно,
    columns=("name", "formula", "carbon_count"),
    show="headings",
    height=10
)
таблица.heading("name", text="Название")
таблица.heading("formula", text="Формула")
таблица.heading("carbon_count", text="Атомов углерода")

таблица.column("name", width=220, anchor="w")
таблица.column("formula", width=160, anchor="center")
таблица.column("carbon_count", width=180, anchor="center")

таблица.pack(padx=15, pady=10, fill="both", expand=True)


окно.mainloop()

```

## Дополнительный опыт: загрузка сразу при открытии

Основной вариант сохраняет кнопку «Показать». Если преподаватель просит показывать данные сразу при запуске, **перед последней строкой `окно.mainloop()`**, после создания и размещения таблицы, добавьте:

```python
показать_алканы()
```

Здесь скобки нужны: мы вызываем функцию сразу. В `command` скобок по-прежнему нет, поскольку там передаём действие на будущее. После опыта можно удалить этот вызов, вернув пустую таблицу при старте.

## Почему окно может ненадолго задерживаться

Запрос выполняется в той же функции обработки событий, что и остальной интерфейс. Для десяти локальных записей это простой учебный вариант. При медленном сервере окно может временно не отвечать; `connect_timeout` ограничивает установку соединения, а не время выполнения любого запроса. Работа с долгими запросами выходит за рамки этого первого приложения.

## Частые ошибки

- Строки удваиваются — проверьте вызов `очистить_таблицу()` перед циклом.
- При старте видны три вещества — остались ручные `insert()`.
- Нажатие ничего не делает — проверьте `command=показать_алканы` и сообщения терминала.
- `NameError: алканы` — цикл оказался вне функции или переменная названа иначе.
- `NameError: таблица` при запуске — функция вызывается до создания виджета, например из-за скобок в `command`.
- Значения попали не в те ячейки — сверяйте порядок трёх столбцов в SQL, индексов кортежа и `values`.
- В pgAdmin данные есть, а запрос Python их не видит — сравните сервер, порт, имя базы и схему.
